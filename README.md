# Employee Salary Calculator

A Java Swing application with an interactive terminal mode for registering employees and calculating salary slips.

## Requirements

Install a JDK so `javac` and `java` are available in Terminal.

## Compile

```sh
javac EmployeeSalaryCalculator.java
```

## Run the graphical app

```sh
java EmployeeSalaryCalculator
```

## Run in Terminal

```sh
java EmployeeSalaryCalculator --console
```

The console menu lets you register employees, calculate salary slips, view all employees entered during that run, and exit. Employee records are kept in memory and cleared when the program exits.
