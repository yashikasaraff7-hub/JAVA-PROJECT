# Employee Salary Calculator

A simple Java-based Employee Salary Calculator developed for **Case Study 145**.

The project calculates employee salary using basic salary, allowances, deductions and employee category.

## Problem Statement

To develop a system that calculates employee salaries based on salary components and employee category.

## Objectives

- Store employee information
- Take salary input
- Calculate allowances and deductions
- Generate net salary
- Display salary details

## Modules

1. Employee Registration
2. Salary Input
3. Allowance Calculation
4. Deduction Calculation
5. Salary Slip

## Technologies Used

- Java
- Java Swing & AWT
- Java Collections
- Scanner

## Programming Concepts

- Variables & Data Types
- Operators & Expressions
- if-else
- switch
- Methods
- Loops
- Classes & Objects
- Constructors
- Encapsulation
- ArrayList / List
